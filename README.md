# pia-bodegaVinos

## Notebooks por neurona

La libreta original [bodegaVinos.ipynb](./bodegaVinos.ipynb) se conserva como referencia completa. Para estudiar cada modelo por separado, se han creado notebooks independientes, cada uno con celdas Markdown que explican el flujo, el funcionamiento de la neurona y la interpretación de sus resultados:

- [neurona_mcculloch_pitts.ipynb](./neurona_mcculloch_pitts.ipynb): clasificador binario basado en reglas y umbral.
- [perceptron_simple.ipynb](./perceptron_simple.ipynb): neurona lineal con pesos aprendidos y umbral calibrado por negocio.
- [perceptron_multicapa_mlp.ipynb](./perceptron_multicapa_mlp.ipynb): red neuronal con capas densas, regularización y selección de arquitectura.

Cada archivo puede ejecutarse de principio a fin de forma independiente. Las tres versiones usan la misma semilla, partición estratificada, análisis exploratorio y función de evaluación para que sus resultados sean comparables.
